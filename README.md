# 🌱 Gather AI
### Grow smarter. Waste less. Gather more.

**Gather AI** is an AI-powered agricultural sustainability platform that helps farmers make smarter crop decisions, buy farming inputs directly, sell agricultural produce without brokers, and connect organic waste with recovery partners.

By bringing crop intelligence, direct agricultural commerce, and organic waste recovery into one platform, Gather AI aims to make agriculture smarter, more accessible, and sustainable.

---

## 🚨 Problem Statement

Agriculture faces three interconnected challenges:

- **Limited crop intelligence:** Farmers often lack accessible and timely guidance to make informed crop management and harvesting decisions.
- **Dependence on intermediaries:** Farmers face difficulties accessing agricultural inputs directly and selling their produce to buyers without unnecessary middlemen.
- **Agricultural waste:** Surplus produce and organic waste often go unused because farmers lack convenient connections with suitable recovery companies.

These challenges affect agricultural efficiency, market access, and sustainable resource utilization.

## 💡 Our Solution

Gather AI addresses these challenges through an integrated agricultural platform powered by AI.

It combines three major capabilities:

1. **Harvest Intelligence** – AI-powered crop guidance and harvest readiness insights.
2. **Direct Agricultural Marketplace** – A platform where farmers can buy agricultural inputs and sell produce directly to companies and buyers.
3. **Organic Waste Recovery** – Connects farmers with recovery partners to give suitable organic waste a productive second life.

---

## ✨ Key Features

### 🌾 1. Harvest Intelligence
- Register and manage crops.
- Track crop growth stages.
- Receive AI-powered crop recommendations.
- Get harvest readiness estimates based on available crop information.
- Identify surplus produce and explore suitable next steps.

### 🛒 2. Direct Agricultural Marketplace

A two-way marketplace designed to reduce dependency on intermediaries.

**BUY**
- Discover fertilizers, compost, and agricultural inputs.
- Explore products from participating sellers.
- Submit purchase enquiries.

**SELL**
- List seeds, grains, fruits, vegetables, and harvested produce.
- Connect directly with potential buyers.
- Receive enquiries and offers.

### ♻️ 3. Organic Waste Recovery
- Register available agricultural and food waste.
- Discover relevant recovery partners.
- Find potential matches based on waste compatibility.
- Submit collection requests.
- Track request progress.

### 🤖 4. Ask Gather AI
An AI-powered assistant designed to help users:
- Understand crop-related questions.
- Receive contextual agricultural guidance.
- Explore platform features.
- Understand potential recovery options.
- Get assistance with relevant platform workflows.

### ⚙️ 5. User Dashboard & Settings
- Centralized dashboard.
- Crop and marketplace overview.
- Recovery request tracking.
- User preferences and account settings.

## 🚀 Getting Started

Follow these steps to run Gather AI locally.

### Prerequisites

- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project directory

```bash
cd gather-ai
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env` file in the project root.

```env
GROQ_API_KEY=your_groq_api_key
```

Get your API key from [Groq Console](https://console.groq.com/).

**Important:** Keep your API key secure. Never expose it in frontend code or commit your `.env` file to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### 6. Build for production

```bash
npm run build
```
